# Welcome to Grimm

Grimm is a quiet place to write Markdown on your Mac. You type, and the page formats itself as you go. There is no preview pane and no toolbar full of buttons, only your words.

This note is a short tour. Edit it, break it, or close it. You can always bring it back from the **Help** menu at the top of the screen, and the **Help** button at the bottom of the sidebar has answers to common questions.

## Who it's for

- People who think in plain text and want it to look good while they write.
- Anyone keeping notes, drafts, journals or docs as `.md` files in a folder.
- Writers who would rather not learn another app.

Your notes are ordinary Markdown files on your own disk. Grimm has no account, no library to import into, and no format of its own. Open a file from anywhere and save it anywhere.

## Start writing

Open a new tab with **⌘N** and type. Markdown you already know just works:

- `#` and a space makes a heading (`##` for a smaller one)
- `**bold**`, `*italic*` and `` `code` `` format as you finish them
- `-` and a space starts a list, `1.` a numbered one
- `[]` and a space makes a checkbox
- `>` and a space starts a quote

Try it on the line below:

- [ ] Type something here
- [ ] Tick this box

Select any text to get a small toolbar for bold, italic, strikethrough, code and links.

## Insert anything with /

On an empty line, type `/` to open the insert menu. From there you can add headings, lists, quotes, dividers, images, code blocks, tables and HTML embeds without lifting your hands from the keyboard.

## Move things around

Hover any block and a grip appears to its left. Drag it to move the block somewhere else. The same works for list items, for the rows and columns of a table, and for tabs.

## Files, folders and tabs

| To do this | Press |
| --- | --- |
| Open a file | ⌘O |
| Open a folder in the sidebar | ⇧⌘O |
| Save a new note, or Save As | ⌘S, ⇧⌘S |
| New tab, close tab | ⌘N, ⌘W |
| Next or previous tab | ⇧⌘], ⇧⌘[ |
| Split the window in two | ⇧⌘\ |
| Show or hide the sidebar | ⌘\ |

Save a new note once to give it a home. After that Grimm saves it for you as you write.

Drag a file from the sidebar onto either side of a split to open it there, or ⌘-click it to open it in the other pane. Grimm reopens your tabs the next time you launch it.

## Make it yours

Click the palette icon at the top right to choose a theme (there are twelve, six light and six dark), a serif, sans or mono typeface, the text size, and whether the page is a centred column or the full width of the window.

## It is still just Markdown

Press **⌘/** at any time to see and edit the raw Markdown behind the page, and again to come back. What is on screen is exactly what is in the file.
