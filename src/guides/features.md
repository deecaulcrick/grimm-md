# Features

Everything Grimm can do, in one place. Reopen this list any time from the **Help** menu at the top of the screen. To see each kind of block on the page, open **Examples** from the same menu.

## Writing

- **Live formatting.** Markdown turns into headings, lists, quotes, bold, italic and code as you type it. No separate preview.
- **Checkboxes.** Type `[]` at the start of a line, or inside a bullet, for a task you can tick. `[x]` makes one that is already done.
- **Selection toolbar.** Select text for bold, italic, strikethrough, inline code and links.
- **Insert menu.** Type `/` on an empty line for headings, lists, quotes, dividers, images, code blocks, tables, embeds and diagrams.
- **Tables.** Add rows and columns, align columns, and drag rows and columns into a new order.
- **Code blocks.** Syntax highlighting for many languages, with a language picker and a copy button.
- **Undo and redo** for everything, including moving blocks.
- **Word count** in the status bar.

## Moving things

- **Drag blocks.** Every paragraph, heading, quote and list item has a grip. Drag it to move the block.
- **Drag table rows and columns** by their handles.
- **Drag tabs** to reorder them, or across to the other pane.
- **Drag files** from the sidebar into either pane.

## Links and embeds

- **Images.** Paste a web address, or upload a picture: it is copied into an `assets` folder beside the note and linked by a relative path, so the note and its pictures move together. Pictures already on your disk show too, whether the link is relative to the note or a full path.
- **Link cards.** A web address on a line of its own is shown as a preview card with the page's title, description and image. The file still contains only the link. Grimm fetches the page once to build the card.
- **HTML embeds.** A code block with the language `embed` is rendered as live HTML in a sandboxed frame, so you can drop in a video, a map or a small widget.
- **Diagrams.** A code block with the language `mermaid` is drawn as a diagram in the note's colours: flowcharts, sequence diagrams, timelines, pie charts and more. Click **Edit source** to change it; the diagram redraws as you type.

## Finding your way

- **Outline.** In a note with a few headings, a small stack of lines appears at the right edge. Hover it to see the outline and click a heading to jump there.
- **Tabs.** Keep several notes open at once.
- **Split view.** Two panes side by side, each with its own tabs. Drag the divider to resize.
- **Sidebar.** Search your notes with ⌘K. Favorites, Folders, Shared and Recents each fold away by their heading. Open or create as many folders as you like with the **+** beside Folders; hover a folder for **+** (new note) and **…**.
- **Favorites.** Star a note from its header to keep it at the top of the sidebar.
- **Rename and move.** Double-click a note's name to rename it; drag it onto a folder to move it. Its images, star, settings and shared link come along. Drag its edge to resize, or hide it; while hidden, hover its icon to peek.
- **Session restore.** The tabs and panes you had open come back at the next launch.

## Appearance

- **Six themes.** Paper, Meadow and Fog for the day; Grimm, Graphite and Nightshift for the night. Paper and Graphite are a light and dark pair.
- **Per-note layout.** Each note picks its own typeface (serif, sans or mono), text size and width from its **…** menu.
- **Ink and highlighter.** Select text to colour it, highlight it, or both, from nine colours.
- **Lock page.** Stops a note from being edited by accident.
- Follows your Mac's light or dark setting the first time you open it.

## Your files

- **Plain Markdown.** Notes are ordinary `.md` files wherever you keep them. Nothing is imported or locked in.
- **Source view.** Press ⌘/ to edit the raw Markdown directly.
- **Front matter is preserved.** YAML at the top of a file is kept as it is.
- **Opens from Finder.** Double-click a Markdown file, or drop one on the window.
- **Autosave.** Once a note has a file, changes are saved a moment after you stop typing, when you close the tab, and when you leave the app. A dot on the tab marks anything not yet written.

## The app

- **Automatic updates.** Grimm checks for a new version when it starts and installs it when you agree. You can also use **Grimm → Check for Updates…**
- **Made for macOS.** A native window, standard menus and the shortcuts you expect.

| ⌘N | New tab |
| ⌘O | Open file |
| ⇧⌘O | Open folder |
| ⌘S | Save |
| ⇧⌘S | Save As |
| ⌘W | Close tab |
| ⇧⌘] and ⇧⌘[ | Next and previous tab |
| ⇧⌘\ | Split view on or off |
| ⌘\ | Sidebar on or off |
| ⌘K | Search notes |
| ⌘/ | Markdown source on or off |
| ⌘Z and ⇧⌘Z | Undo and redo |
| ⌘B, ⌘I, ⌘E | Bold, italic, inline code |
